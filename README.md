# 周历小窗 + 简洁皮肤（给 Super Productivity 用）

不改 Super Productivity 的源码，它升级不受影响。

## 周历小窗

- 打开：开始菜单搜「周历小窗」。
- 前提：设置 → 更多设置 → 「启用本地 REST API」已勾选。Super Productivity 没开的话，小窗会自己把它打开（最小化到托盘，不弹窗口），等几秒就连上。
- 用法：输入框回车＝加到今天；先点某天的日期，再输入＝加到那天；拖任务到别的日子＝改日子；拖到「还没排日子」＝取消日子；双击标题＝改名；点圆圈＝完成。
- 顶栏：按住空白处拖动窗口；‹ › 翻周，点「本周」回到本周；图钉＝置顶开关；—＝收起成小条（显示今天还剩几件和下一件，点一下展开，按左边的点阵拖动）；▦＝平面视图；×＝关小窗。
- 窗口位置、大小、置顶、收起状态记在 `config.json`（屏幕像素）。记下的位置不在任何屏幕上时（比如拔了显示器），回到主屏右上角。
- 小窗空白时看 `last_poll.txt`：`ok=False` 说明连不上主程序。

文件：`mini.py`（窗口和接口调用）、`ui.html`（界面）、`.venv`（Python 环境，装了 pywebview 5.4）。

## 平面视图（日 / 周 / 月 / 学期）

- 打开：小窗右上角的 ▦ 按钮。
- 顶上四个字切换视图，快捷键 1–4；按 T 回到今天。点任何格子里的日期数字，直接跳到那天的日视图。
- 规则只有一条：点空白处就打字，回车加上；拖任务就是改它。
  - 格子里：开头写 `!` 记成那天截止。拖到别的格子＝换天；拖到右边＝取消日子；拖到底部红框＝删除（会先问）。
  - 日视图：左边是时间轴。点空白处＝在那个时刻加一件；拖到时间轴上＝定时间（15 分钟一格）；拖下边缘＝改时长；拖到「没定时间」＝去掉时间，日子不变。←/→ 翻天。
- 课表：右上角 ⋯ → 课表 → 选 .ics 文件；也可以直接把 .ics 文件拖进窗口。课在日视图里是灰色斜纹块，周视图格子顶上也会列出来。课表存在 `courses.json`，重新导入会整份替换。还没设期末的话，最后一节课那天会自动当成期末。
  - 简课表里导出：设置 → 导出到日历（.ics）→ 生成并分享，发到电脑（微信/QQ 文件传输助手都行）。
  - 别的课表 App 导出的 .ics 也能用，每周重复的写法也认。
- 过期没做的任务显示在今天，前面标原来的日期（红色），拖一下才算重新排。
- 右上角 ⋯ 里还有：换主题（纸墨 / 石墨 / 纸张 / 冷蓝 / 柔彩 / 极简 / 夜间，小窗跟着换；纸墨是默认：暖白纸色、朱砂红，日期和标题用思源宋体、正文用思源黑体，两种字体 Windows 11 自带；纸墨和石墨都跟着系统深浅色走）、期末日期、打开主程序。

文件：`board.html`（平面视图）、`themes.css`（七套主题，两个窗口共用）、`drag.js`（两个窗口共用的拖拽）、`courses.json`（导入的课表）。

拖拽怎么做的：没用浏览器自带的拖放（在 WebView2 里起步慢、跟手一卡一卡），而是 `drag.js` 自己跟着指针挪一份拷贝。小窗的顶栏用 CSS `app-region: drag` 交给 WebView2 当标题栏，拖窗口和普通窗口一样由系统负责；万一没接管，`mini.py` 的 `start_drag` 兜底，两条路不会同时生效。

## 皮肤

- 现在是「纸墨」配色和字体，和平面视图一致。源文件：`styles.css`。生效的那份在 `%APPDATA%\superProductivity\styles.css`，改完复制过去，主程序立即刷新。
- 恢复原样：删掉 `%APPDATA%\superProductivity\styles.css`。

## 开机自启

已经装好：`shell:startup` 文件夹里有「周历小窗」快捷方式。开机后小窗自己起来，主程序没开的话小窗会把它最小化打开。不想自启就删掉那个快捷方式。


## 清晰度（DPI）

程序按「每块屏幕各自的缩放」声明 DPI（Per-Monitor V2，见 mini.py 的 `_dpi_aware`）。以前用的是整个系统一个缩放：换了显示器或改了缩放、又没重新登录时，Windows 会把整个窗口按位图拉大，字发糊。窗口大小在 config.json 里按 100% 缩放存（`units: "css"`），换到别的缩放也一样大。

## 主程序自动打开（看门狗）

小窗后台每 3 秒看一次主程序本地接口的端口（mini.py 的 `_watchdog`）：主程序没在运行就最小化打开它。只开，不关。
每次打开、连上、断开都记在 `mini.log` 里，超过 200KB 自动清空。

## 为什么开机连不上（2026-11-24 查清）

Claude Code 的终端跑在沙盒里，用户的 AppData\Roaming 文件夹在沙盒里外是两份。当初从沙盒里装、开的主程序，
「本地 REST API」的开关和令牌只写进了沙盒那份；开机和手动打开的主程序用的是外面那份，开关是关的、也没有令牌，所以小窗连不上。
修法：在平时用的主程序里 设置 → 其他（Misc）→ 打开「本地 REST API」，一次即可（打开时会自己生成令牌）。
小窗每次开机还会把 `styles.css` 放进主程序的数据文件夹，所以纸墨皮肤也会生效。
